# Aster 中文前端教程

> 本文是中文主线教程，英文独立教程见 [`ASTER-EN-QUICKSTART.md`](ASTER-EN-QUICKSTART.md)。中文与英文是两种文件级语法：一个 `.ast` 文件选择一种语言，两个语言会归一到同一套 AST、类型和 AArch64 ABI。完整设计与阶段状态见 `ASTER-CN-DESIGN.md`。

## 0. 先看一个最小程序 / The smallest program

中文文件使用 `启动方法` 作为入口，块用 `结束 方法` 闭合：

```aster
// aster:language=zh
方法 启动方法(): 整数
    变量 答案: 整数 = 40 + 2
    返回 答案
结束 方法
```

英文文件使用 `main`，块用花括号闭合：

```aster
// aster:language=en
fn main(): i32 {
    let answer: i32 = 40 + 2;
    return answer;
}
```

两段程序的入口、返回类型和机器级调用约定相同。双语前端的返回类型统一写在冒号后；省略返回类型也可以，`方法 f()` / `fn f()` 等价于 `方法 f(): 空` / `fn f(): void`。`->` 只在中文侧保留给遍历循环与枚举循环的对象分隔符（英文侧用 `in`），不用于返回类型。

## 1. 构建与命令 / Build and commands

### 构建编译器

在 Aster 仓库根目录执行：

```sh
cmake -S . -B build/cn
cmake --build build/cn --target aster
```

上面的构建目录若之前配置成 `Debug`，编译器 ELF 会包含大量 DWARF 调试段，文件可能比 `Release` 构建大数倍；这不会放大中文程序生成的对象或最终程序。发布或日常使用可单独配置 Release 目录：

```sh
cmake -S . -B build/cn-release -DCMAKE_BUILD_TYPE=Release
cmake --build build/cn-release --target aster
```

中文程序若链接 `aster_std.ast`，会把标准库对象中的运行时函数一并带入最终 ELF；不使用标准库运行时的最小程序仍保持几 KB 规模。

以下命令假设 `aster` 已在 `PATH` 中。该前端生成 AArch64 ELF64 可重定位对象；链接产物也是 AArch64 程序，只有在 AArch64 Linux 上才能直接运行，其他主机需要相应的模拟器或目标设备。

## 2. 文件语言、关键字与类型 / File language, keywords, and types

语言模式按以下顺序确定：命令行 `--language`、文件附近的 `// aster:language=zh|en`、项目配置，最后是中文默认值。一个文件只使用一套结构性关键字；标识符、字符串和注释可以包含另一种语言。

| 中文 | English | 作用 |
| --- | --- | --- |
| `方法` | `fn` | 顶层函数或类成员方法 |
| `变量` | `let` | 可变局部、全局或类字段 |
| `常量` | `const` | 必须有编译期初值且不可赋值 |
| `返回` | `return` | 返回值或提前退出无返回值方法 |
| `如果` / `否则如果` / `否则` | `if` / `else if` / `else` | 条件分支 |
| `循环` | `while` | 条件循环 |
| `计次循环` | `for` | 起点、终点和可选步长的计次循环 |
| `遍历循环` | `foreach` | 遍历一维定长数组或字符串字节 |
| `枚举循环` | `enumloop` | 枚举结构体或类的公开字段 |
| `假如` / `是` | `switch` / `case` | 整数或枚举匹配 |
| `退出循环` / `跳过循环` | `break` / `continue` | 循环控制 |
| `类` / `接口类` / `结构` / `枚举` | `class` / `interface class` / `struct` / `enum` | 类型声明 |
| `包名` | `package` | 文件开头的源码包声明 |
| `空` | `void`（类型）、`null`（英文值） | 无返回值类型或空指针值 |

常用类型按一一对应关系书写：`字节/i8`、`短整数/i16`、`整数/i32`、`长整数/i64`、`u字节/u8`、`u短整数/u16`、`u整数/u32`、`u长整数/u64`、`单精度/f32`、`小数/f64`、`逻辑型/bool`、`字符/char`、`字符串/string`、`指针/ptr`。中文布尔类型只有 `逻辑型`，`布尔` 是普通标识符；英文布尔值写 `true`、`false`。类型、参数和字段都使用冒号，例如 `变量 数量: 整数` 与 `let count: i32`。

控制流示例：

```aster
// zh
计次循环 (i = 1, 3)
    如果 i == 2
        跳过循环
    结束 如果
结束 计次循环

// en
for (i = 1, 3) {
    if (i == 2) { continue; }
}
```

数组遍历在中文中用 `->`，英文中用 `in`；`->` 不是返回类型符号：

```aster
遍历循环 (索引, 项 -> 数组)
    总和 = 总和 + 项
结束 遍历循环
```

```aster
foreach index, item in array {
    sum = sum + item;
}
```

绑定的索引和元素是只读的。`枚举循环 (字段 -> 对象)` / `enumloop field in object` 只提供结构体或类的公开字段。

## 3. 注解系统 / Annotation system

注解只修饰紧随其后的一个声明；多个注解可以叠加，但权限注解只能选一个。英文不使用 `restricted`：中文 `@受限` 对应 `@protected`。

| 中文注解 | English annotation | 适用范围与语义 |
| --- | --- | --- |
| `@静态` | `@static` | 类字段或类方法；通过 `类名.成员` / `Class.member` 访问 |
| `@构造` | `@constructor` | 类实例构造器；必须返回 `空` / `void` |
| `@重写` | `@override` | 明确标记继承方法重写，签名必须完全相同 |
| `@隐藏` | `@private` | 类成员只在声明类可见；顶层声明只在声明文件可见 |
| `@受限`、`@受限.类` | `@protected` | 类成员在声明类和子类可见；顶层只接受 `@受限`（中文拼写，按声明文件限制），英文顶层须写 `@private`，顶层 `@protected` 不接受 |
| `@导入("包")`.别名("名")` | `@import("package").alias("name")` | 文件级源码包导入与本地别名 |

注解参数只接受字符串或整数字面量。`@静态` 不适用于顶层函数或接口方法；静态字段不能通过对象访问，静态方法不能使用 `本对象/this`。

## 4. 类、构造器、继承与接口 / Classes, constructors, inheritance, and interfaces

中文类使用块结束关键字，英文类使用花括号。下面的两段分别演示实例字段、构造器、静态字段、继承、重写和 `super`：

```aster
// aster:language=zh
类 计数器
    变量 值: 整数
    @静态
    变量 总数: 整数 = 0

    @构造
    方法 初始化(初值: 整数): 空
        本对象.值 = 初值
        计数器.总数 = 计数器.总数 + 1
    结束 方法

    方法 读取(): 整数
        返回 本对象.值
    结束 方法
结束 类

类 加倍计数器 : 计数器
    @重写
    方法 读取(): 整数
        返回 父对象.读取() * 2
    结束 方法
结束 类
```

```aster
// aster:language=en
class Counter {
    let value: i32;
    @static let total: i32 = 0;

    @constructor
    fn initialize(initial: i32): void {
        this.value = initial;
        Counter.total = Counter.total + 1;
    }

    fn read(): i32 { return this.value; }
}

class DoubleCounter: Counter {
    @override
    fn read(): i32 { return super.read() * 2; }
}
```

`类名()` 分配对象并先初始化字段；有 `@构造` 时再调用构造器。派生类构造器可以把 `父对象(参数…)` / `super(args)` 写在第一句。接口类只声明方法签名，返回类型可以省略，省略时按 `空` / `void` 处理；接口可用一个冒号继承先声明的接口，继承全部方法签名，例如 `接口类 可增强 : 可读` / `interface class Readable: BaseReadable`。类用相同的冒号实现接口：`类 书本 : 可读` / `class Book: Readable`。接口实现方法必须公开，`@隐藏`、`@private` 或 `@受限`、`@protected` 方法不能满足公开接口契约；参数类型、函数指针参数签名和返回类型均须匹配。实例调用按运行时对象分派，`父对象/super` 直接调用父类实现。

接口值也可以保存在结构体或类的字段中，以及一维定长数组元素中；读取出来后仍通过对应接口的方法表分派：

```aster
// aster:language=zh
接口类 可取值
    方法 获取(): 整数
结束 接口类

类 项目 : 可取值
    方法 获取(): 整数
        返回 21
    结束 方法
结束 类

结构 结构容器
    值: 可取值
    列表: 可取值[2]
结束 结构

类 类容器
    变量 值: 可取值
    变量 列表: 可取值[2]
结束 类

方法 启动方法(): 整数
    变量 结构对象: 结构容器
    结构对象.值 = 项目()
    结构对象.列表[0] = 项目()
    变量 类对象: 类容器 = 类容器()
    类对象.值 = 项目()
    类对象.列表[0] = 项目()
    返回 结构对象.值.获取() + 结构对象.列表[0].获取() + 类对象.值.获取() + 类对象.列表[0].获取() - 84
结束 方法
```

静态字段还支持函数指针及一维数组：

```aster
// aster:language=zh
方法 加二(值: 整数): 整数
    返回 值 + 2
结束 方法

类 回调表
    @静态
    变量 回调: 方法(整数): 整数 = 加二
    @静态
    变量 回调数组: 方法(整数): 整数[2] = [加二, 加二]
    @静态
    变量 数值: 整数[2] = [7, 8]
结束 类

方法 启动方法(): 整数
    返回 回调表.回调(40) + 回调表.回调数组[1](1) + 回调表.数值[0]
结束 方法
```

```aster
// en
fn addTwo(value: i32): i32 { return value + 2; }
class Callbacks {
    @static
    let callback: fn(i32): i32 = addTwo;
    @static
    let callbackArray: fn(i32): i32[2] = [addTwo, addTwo];
    @static
    let values: i32[2] = [7, 8];
}
fn main(): i32 {
    return Callbacks.callback(40) + Callbacks.callbackArray[1](1) + Callbacks.values[0];
}
```

函数指针字段及函数指针数组按完整签名检查；标量结构体静态字段和一维结构体静态数组也支持显式初值、默认值、嵌套读取和写入；字符串数组支持字面量初值和默认空串。

实例字段也可以保存带完整签名的函数指针或一维函数指针数组；它属于对象布局，派生类对象会继承该字段，调用时读取当前对象中的字段值。结构体字段也支持同样的一维函数指针数组，数组元素按字段签名检查：

```aster
类 工作器
    变量 回调: 方法(整数): 整数 = 加二
    方法 运行(值: 整数): 整数
        返回 本对象.回调(值)
    结束 方法
结束 类
```

```aster
结构 回调盒
    回调们: 方法(整数): 整数[2]
结束 结构
```

## 5. 包名、模块导入与跨语言调用 / Packages and imports

包名是源码声明，不需要额外的 `模块.ast` 描述文件。它必须是去掉注释后的第一个声明，同一个包的多个源文件必须声明相同的包名和别名：

```aster
// Chinese source
包名 示例.数学 = standard.math
方法 平方(值: 整数): 整数
    返回 值 * 值
结束 方法
```

```aster
// English source in the same package identity
// aster:language=en
package 示例.数学 = standard.math;
fn cube(value: i32): i32 { return value * value * value; }
```

调用方按包名导入，别名只影响当前文件：

```aster
// aster:language=zh
@导入("示例.数学").别名("数学库")
方法 启动方法(): 整数
    返回 数学库.平方(4) + 数学库.cube(2)
结束 方法
```

```aster
// aster:language=en
@import("standard.math").alias("math")
fn main(): i32 { return math.平方(4) + math.cube(2); }
```

编译时把源码包目录加入搜索路径：

```sh
aster build-cn-obj --module-dir packages app.ast -o app.o
aster link-obj app.o -o app
```

包内公开的函数、全局值、类、接口、枚举和静态成员都可导入；`@隐藏`/`@private` 与 `@受限`/`@protected` 会在导入处执行权限检查。跨包静态函数指针字段可以直接调用，例如 `alias.Callbacks.callback(40)`；公开顶层方法也可写成 `alias.addTwo` 作为函数指针初值或数组元素。导入接口可以接收包内实现类，接口方法仍按运行时方法表分派，类方法内部的函数指针字段签名保持有效。字段的声明包、声明类和调用方语言不会改变签名规则。

跨包权限示例：

```aster
// package source
fn addTwo(value: i32): i32 { return value + 2; }
class CallbackBox {
    @static
    let callback: fn(i32): i32 = addTwo;
    @private
    @static
    let hidden: fn(i32): i32 = addTwo;
    @protected
    @static
    let restricted: fn(i32): i32 = addTwo;
}
class CallbackChild: CallbackBox {
    @static
    fn run(value: i32): i32 {
        return CallbackChild.callback(value);
    }
    @static
    fn runRestricted(value: i32): i32 {
        return CallbackChild.restricted(value);
    }
}
```

导入方可以调用 `CallbackChild.run(40)`、`CallbackChild.runRestricted(40)` 或公开的 `CallbackBox.callback(40)`；子类内部可以访问 `restricted`，类外直接读取 `hidden` 会得到 private 诊断，直接读取 `restricted` 会得到 protected 诊断。受限成员的英文注解固定为 `@protected`，不会使用 `@restricted`。

## 6. 结构、枚举、闭包与格式化 / Structs, enums, closures, and formatting

结构体是值类型，字段用 `名: 类型` 声明；枚举在中文中使用 `结束 枚举`，英文使用花括号：

```aster
// zh
枚举 颜色
    红色
    蓝色 = 4
结束 枚举
```

```aster
// en
enum Color { Red, Blue = 4 }
```

匿名方法和闭包也按语言模式书写。中文使用 `方法 [捕获列表]...结束 方法`，英文使用 `fn [captures]...}`；类型分别是 `闭包(整数): 整数` 与 `closure(i32): i32`。捕获按值复制到环境中，可作为局部变量、结构体字段、数组元素或回调参数。

格式化器固定使用四个空格缩进，并保留字符串和注释内容：

```sh
aster fmt source.ast
aster fmt --check source.ast
aster fmt --write source.ast
```

`examples/cn/hello.ast` 展示计次循环，`examples/cn/oop.ast` 展示类、实例方法、静态方法和共享字段。编辑器可以调用 `src/cn_formatter.hpp` 中的 `aster_cn::formatSource`。

## 7. 声明式布局（D-2a）/ Declarative layout

布局声明是具名函数，返回 `视图` 值；体即树表达式。事件块是顶层块，表头用**名字**不用数字键；布局块与事件块用花括号 `{}` 闭合，体内的 `如果` 仍用 `结束 如果`。普通方法返回类型写在冒号后（`方法 建立界面(): 视图`），不得用 `->` 表示方法返回类型：

```aster
事件 加:被单击() {
    g_app.计数 = g_app.计数 + 1
    设置状态(1, g_app.计数)
    刷新()
}

布局 page_counter(s: 指针<应用>, 用户: 指针): 视图 {
    列 主列, 内边距(20), 间隙(16) {
        标签 标题, 指针("计数器")
        行 按钮行, 间隙(12) {
            按钮 减, 指针("-")
            数字 计数, s.计数
            按钮 加, 指针("+")
        }
        按钮 重置, 指针("重置")
        如果 s.计数 == 0
            标签 零, 指针("计数为零。")
        否则
            标签 非零, 指针("计数非零。")
        结束 如果
    }
}
```

节点行是 `种类 名, 参数..., 修饰符调用..., { 子节点行... }`，不能出现在参数位置。节点名即身份：同一布局声明内名字唯一，`key = FNV-1a(声明名.节点名)`（32 位，名字符串按 UTF-8 字节算）；同一应用内碰撞是编译错误，可用 `键 = N` 显式覆盖（`列 主列, 键 = 1001, 内边距(20) { ... }`，`键 = N` 是具名覆盖参数，不是修饰符）。`键(名)` 是编译期 builtin，折叠成 i32 常量（`文本取值(键(输入框))`）；引用不存在的节点名即编译错误。修饰符是调用形态（`内边距(20)`、`间隙(16)`、`背景(...)`、`圆角(...)`、`字号(...)`、`前景色(...)`、`长按选中(...)`、`尺寸(...)`、`对齐(...)`、`权重(...)`、`生长(...)`），同一节点行里重复即编译错误，字符串维度不接受；`生长` 暂无落点——新线框架没有 `aui_grow`，写了 `生长(...)` 即编译错误，不静默丢弃。事件块体里只能用全局量与 getter，不能捕获 build 局部量；同一 (key, 事件) 写两块即编译错误；树表达式之后的语句是挂载后语句，按源码顺序执行。节点种、修饰符、事件种的完整表见设计文档 `docs/ASTER-CN-DESIGN.md` §2.16。自举编译器不接受 D-2a 形态（`布局`/`事件`/`键()` 进 stage 即报错，见设计文档 §3.7）。

## 8. 命令与实现参考 / Command and implementation reference

### 编写并构建中文程序

新前端默认按中文模式解析。也可以在文件开头明确标注语言模式：

```aster
// aster:language=zh

方法 启动方法(): 整数
    变量 合计: 整数 = 0
    计次循环 (i = 1, 3)
        合计 = 合计 + i
    结束 计次循环
    假如 合计
        是 6
            返回 0
        否则
            返回 1
    结束 假如
结束 方法
```

保存为 `hello.ast`，然后编译并链接：

```sh
aster build-cn-obj hello.ast -o hello.o
aster link-obj hello.o -o hello
```

### 双语命令与中文文件名

CLI 保留英文子命令，同时提供对应的中文别名。中文别名只替换子命令本身，选项仍使用英文拼写：

```sh
aster 编译双语对象 你好.ast -o 你好.o
aster 链接可执行文件 你好.o -o 你好
```

例如，`编译双语对象` 对应 `build-cn-obj`，`链接可执行文件` 对应 `link-obj`；其他别名可用 `aster 帮助` 查看。英文命令仍然有效。

在 UTF-8 的 Linux/Android（包括 Termux）环境中，源文件名、目录名和输出文件名都可以使用中文。CLI 将路径按系统收到的 UTF-8 字节交给文件 API，不要求 ASCII 文件名。单文件对象仍可使用 `编译双语对象`（`build-cn-obj`）；项目级 `构建项目`（`build`）保持命令名不变，并在 `aster.proj` 的 `[language]` 配置或源文件语言声明启用时编译双语源文件。没有双语配置的旧项目继续走旧前端。

双语项目的 `build` 会将项目文件、项目源代码和包源码纳入缓存指纹。重复构建会复用生成的对象后重新链接；修改任一相关 `.ast` 文件、语言配置或编译选项都会使缓存失效。需要强制重建时使用 `aster build --no-cache`。

项目需要从外部目录加载包时，可在保持 `build/run` 命令不变的情况下添加 `--module-dir DIR`；该目录中的 `.ast` 包源码也会进入缓存指纹：

```sh
aster build --module-dir packages
aster run --module-dir packages
```

项目测试也使用同一套语言选择和包搜索规则：`aster test --module-dir packages` 会编译中英文测试源，测试对象按项目配置、项目源、测试源、包源码、包搜索根顺序和编译选项建立缓存；命中缓存时直接复用测试对象并重新链接运行，修改任一输入或调整搜索根顺序都会重新编译。

`aster fmt <source.ast>`（中文命令 `aster 格式化源码`）会把格式化后的源码写到标准输出，默认按文件语言标记选择中文或英文；`--write` 原子写回源文件，`--check` 检查格式是否规范。格式化器固定使用四空格缩进，清除行尾空白、统一为 LF 并确保文件以换行结束；表达式、注释和字符串内容保持原样。IDE 可调用 `src/cn_formatter.hpp` 中的 `aster_cn::formatSource` 接口。

双语前端诊断带有稳定错误码，例如 `[A-010]` 表示代码块结构不匹配，`[A-050]` 表示类型检查失败。中文源码显示中文摘要，英文源码显示英文摘要；括号内仍保留详细原因，便于命令行脚本和 IDE 读取。相同语义错误在两种语言中使用相同错误码。

需要调用 C 或系统库函数或变量时，中文源码用 `外部("ASCII符号") 方法/变量 中文名` 指定 ABI 符号，英文源码继续使用 `extern fn` / `extern let`。中文映射字符串必须非空且只含 ASCII；外部全局变量不能写初值，类型可以是标量、定长数组、字符串或函数指针：

```aster
外部("puts") 方法 输出(文本: 指针): 整数
```

```aster
extern fn puts(text: ptr): i32;
```

```aster
外部("native_counter") 变量 计数: 整数
```

```aster
extern let native_counter: i32;
```

仓库内的中文示例位于 `examples/cn/`：`hello.ast` 展示计次循环，`oop.ast` 展示对象、实例方法、静态方法和共享静态字段。

程序入口必须返回 `整数`（`i32`）：中文入口名为 `启动方法`，英文入口名为 `main`。中文模式用换行或分号结束语句，并用 `结束 结构名` 闭合代码块。计次循环绑定 `i` 在循环体内只读。

中文枚举也使用块结束形式，不使用英文花括号：

```aster
枚举 颜色
    红色
    绿色 = 4
结束 枚举
```

当前也支持顶层可变标量变量；带初值的变量在程序进入入口方法前初始化：

```aster
变量 已启动: 逻辑型 = 假

方法 启动方法(): 整数
    已启动 = 真
    如果 已启动
        返回 0
    否则
        返回 1
    结束 如果
结束 方法
```

包名在源码第一个非注释声明处给出；同一个包可以由多个声明相同包名的 `.ast` 文件组成。导入按包名索引源码，不需要额外的模块清单：

```aster
包名 示例.数学
方法 平方(值: 整数): 整数
    返回 值 * 值
结束 方法
```

调用文件可写 `@导入("示例.数学").别名("数学库")`，然后调用 `数学库.平方(4)`。搜索顺序是调用文件目录、`--module-dir DIR` 指定的目录、项目文件所在目录。标准库源码目录目前通过 `--module-dir` 加入搜索路径。

双语包可在同一包头声明规范名和别名，例如 `包名 标准库.数学 = standard.math`（英文文件使用 `package 标准库.数学 = standard.math;`）。中文入口导入 `标准库.数学`，英文入口导入 `standard.math`，两者会解析为同一包；包名、类型名、字段名和方法名都按源码声明的精确拼写匹配，不会根据源文件语言自动翻译。子类也可以在导入方继承包内类，并按声明类与子类关系使用 `@受限`/`@protected` 成员。标准库字符串入口使用 `标准库.文本 = standard.text`，避免把保留的类型名 `字符串/string` 用作包名。

### 编写英文程序

英文文件可在文件开头指定模式，也可在编译时指定：

```aster
// aster:language=en

fn main(): i32 {
    let answer: i32 = 42;
    return answer;
}
```

```sh
aster build-cn-obj hello-en.ast -o hello-en.o
# 或显式选择模式
aster build-cn-obj --language en hello-en.ast -o hello-en.o
```

中文程序用 `启动方法` 声明入口；英文程序用 `main`。中文 `启动方法` 会归一化为与英文 `main` 相同的 AST 名称和 ABI 入口。双语前端的返回类型统一写在冒号后，例如 `方法 启动方法(): 整数` 或 `fn main(): i32`；`->` 不属于双语前端的返回类型语法。主编译器与 `build-cn-obj` 现在统一用 `:` 写返回类型。单个文件只能使用一种结构性语法，不能混写中文和英文关键字。

### 链接标准库

不使用标准库运行时函数时，可直接链接程序对象。类名 `类名()` 对象构造、字符串拼接、字符串字典序比较、字符串与 `字符串视图` 的转换会引用 `aster_std.ast` 中的运行时符号，此时先构建标准库对象，再将它一并链接：

```sh
aster build-obj stdlib/aster_std.ast -o aster_std.o
aster link-obj hello.o aster_std.o -o hello
```

手动使用 `link-obj` 时仍会整体并入每个输入对象；它不会从独立的标准库对象中按引用挑选函数。双语项目使用 `aster build/run` 时，编译器会在无 `-g` 的链接中从合并对象的 `_start` 做函数级可达性分析，只保留被调用或取地址的函数；带 `-g` 时为保留完整调试信息而关闭裁剪。这样项目源文件中未使用的标准库函数不会进入最终 ELF。手动链接可在 `link-obj` 或 `link-pie` 后加 `--gc-sections` 开启同一裁剪。ELF 符号表字符串区里的 NUL 字节只是名称终止符，不是额外符号。

标准库函数由同一份 Aster 实现提供。当前已接入最小双语字符串包 `标准库.文本 = standard.text`：中文入口为 `长度`、`拼接`、`相等`、`更小`，英文入口为 `length`、`concat`、`equals`、`less`。这些入口共享字符串运行时、UTF-8 字节序和 `字符串视图/string_view` 的 ABI；例如 `文本.长度(文本.拼接("A", "ster"))` 与 `text.length(text.concat("A", "ster"))` 语义相同。其余冷门 API 仍按阶段补齐。

### 类成员注解

`@静态` 方法通过类名调用，不会接收隐藏的 `this` 参数。`@静态` 字段也通过类名读写，并由所有对象共享。字段可为标量、字符串、函数指针、结构体或一维定长数组；函数指针字段可用 `类名.字段(参数…)` 调用，数组通过 `类名.字段[下标]` 访问，声明初值须是长度匹配的字面量数组：

```aster
类 计算器
    @静态
    变量 已创建数量: 整数 = 0

    @静态
    方法 加一(): 整数
        计算器.已创建数量 = 计算器.已创建数量 + 1
        返回 计算器.已创建数量
    结束 方法
结束 类

方法 启动方法(): 整数
    返回 计算器.加一()
结束 方法
```

字段和方法默认公开。类成员上的 `@隐藏` 只在本类可见，英文写作 `@private`；`@受限` 等价于 `protected`，本类和子类可见，英文写作 `@protected`，旧写法 `@受限.类` 仍作为中文同义拼写接受。顶层声明没有继承关系，顶层 `@受限` 限定为声明源文件可见，英文写作 `@private`。

匿名方法可写作 `方法 [捕获列表] (参数): 返回类型 ... 结束 方法`；英文对应 `fn [captures] (params): Type { ... }`。闭包类型签名写作 `闭包(参数类型, ...): 返回类型` / `closure(P, ...): R`，允许嵌套。零捕获和按值捕获闭包支持显式或推断局部类型、赋值和调用，也可以作为结构体字段或定长数组元素调用，值采用 16 字节 `{代码指针, 环境指针}` 表示；捕获环境由标准库 `alloc` 分配，创建时复制标量、指针、对象指针或固定长度局部数组，闭包体内的赋值只修改环境副本；数组捕获按原长度逐元素复制。捕获项和闭包体会经过独立作用域检查，未知捕获及超过 256 字节的环境会报错。闭包值作为回调参数传给 `方法(指针): 返回类型, 用户: 指针` / `fn(ptr): R, user: ptr` 注册方法时，编译器会生成静态 adapter；它保留 `用户/user` 参数，并为每次注册分配独立上下文。adapter 可用于表达式语句、局部变量初始化、赋值右值、返回值、`如果/if` 条件、`循环/while` 条件、计次循环的起点/终点/步长、匹配主题和嵌套表达式，也支持结构字段和数组元素中的闭包值；这些一次性位置按源码顺序求值。

### 当前支持范围

- 方法、局部变量与常量、基本标量类型、结构体声明和局部成员访问。
- 方法返回类型可省略；`方法 f()` / `fn f()` 与 `方法 f(): 空` / `fn f(): void` 等价，均表示无返回值。
- 顶层可变标量变量与顶层标量常量；常量需显式类型和编译期可求值的标量初值。
- 一维固定长度全局标量数组，支持下标读写、元素列表初始化和单值重复初始化。
- 标量结构体全局变量与常量，支持编译期嵌套字面量初始化；未初始化结构体可含数组字段，但含字符串字段时必须显式初始化。结构体字面量暂不支持数组字段或指针/字符串字段。
- 类字段的 AAPCS64 布局、强类型对象指针及通过引用读写字段；字段可在声明处初始化。`@静态` 字段使用独立共享存储，不进入对象布局，只能通过类名访问；静态、实例类字段和结构体字段都支持标量、字符串、单个结构体、函数指针、一维定长标量数组、一维结构体数组、一维函数指针数组和一维字符串数组，结构体字段及数组元素支持字面量初值、默认值及嵌套读写，字符串数组默认填充空串，函数指针可通过字段调用，数组元素可通过下标读写或调用，数组初值须为等长的字面量数组。对象先递归设置实例字段默认值，再按父类到子类执行实例字段初值（声明顺序），最后执行该类构造器；固定数组字段的初值须是长度完全匹配的数组字面量。`类名()` 使用标准库 arena 创建对象。`@构造` / `@constructor` 可标记一个 void 实例构造器，`类名(参数…)` 在初始化后调用它；未声明构造器的类仍用 `类名()`。派生类构造器第一句可写 `父对象(参数…)` / `super(args)` 调用父类构造器，参数表达式在该派生构造器作用域内求值；各级构造器按祖先到子类顺序运行，构造阶段虚派发随当前构造类切换。实例方法可通过 `对象.方法(…)` 调用并使用 `本对象/this.字段`；`@静态` 方法通过 `类名.方法(…)` 调用，不带隐藏对象参数。`@重写` / `@override` 显式标记继承方法重写，要求参数、返回类型和函数参数签名完全匹配；普通对象调用按运行时对象分派，`父对象/super.方法(…)` 直接调用父类实现。字段和方法支持 `@隐藏`、`@受限` 与 `@受限.类`；支持单继承和父类字段前缀布局，派生类引用可上转为父类引用。接口声明可用 `类 A : 接口名` 做编译期签名校验。父类或接口须先声明；类引用变量省略初值时仍为空指针。
- `如果`、条件循环、计次循环、固定长度局部数组遍历、字符串字节遍历、枚举声明、整数/枚举匹配，以及结构体和类对象的枚举循环；类对象枚举只公开字段。
- UTF-8 字符串字面量、`==`/`!=` 内容比较、`+` 拼接、`<`/`<=`/`>`/`>=` 字节字典序比较，以及 `字符串` 与 `字符串视图` 的显式双向转换。
- 自动初始化后未再次赋值的局部变量、数组或结构体字段，会在语义检查成功后收到值保持不变的提示。

类引用变量省略初值时为空指针；调用空类引用的实例方法，读取、写入它的实例字段，或用它做 `枚举循环` 对象，会触发 `BRK #1`。

### 当前限制

- `build-cn-obj` 处理单个双语源文件；项目的 `build`/`run` 命令保持原名，在项目语言配置或源文件语言声明启用时编译当前已接通的双语语言子集。没有启用双语配置的旧项目继续使用旧前端。
- 全局结构体数组支持一维固定长度声明、结构体字面量列表初始化（遵循结构体常量字段限制）、默认值、下标成员读写；含字符串字段的结构体不能用于全局数组字面量初始化，未初始化的含字符串字段结构体数组也不支持。方法参数支持一维固定长度数组，数组按地址传入，函数体内可读写元素；参数记录声明长度供边界检查使用，具名数组实参须同时匹配元素类型和长度。闭包参数暂不支持数组；多维数组参数、范围匹配和字符串匹配尚未接入。全局字符串数组支持一维声明、字面量初始化、默认空串、下标读写和内容比较。接口引用使用对象/方法表对，支持局部和全局初始化、结构体字段、类字段、局部数组及结构体/类定长数组元素、函数参数/返回值、类到接口的隐式转换及运行时方法调用；接口值允许为空，调用接口方法前会检查对象指针和方法表指针，任一为空时触发 `BRK #1`；复杂接收者会先保存后分派，避免重复求值。回调 adapter 会为每次注册分配独立上下文；上下文来自进程级增长 arena，编译器不自动释放，因此注册函数返回后仍可使用延迟回调。分配失败时 thunk 返回返回类型的零值；上下文生命周期由注册方持有。
- 字符串按 NUL 结尾字节串处理，遍历按 UTF-8 字节进行；`字符串视图` 不拥有数据，必须保证它引用的字符串仍有效。
- 使用对象构造或字符串运行时功能时须链接标准库对象；编译器生成 AArch64 目标，不会为本机 x86-64 生成程序。
