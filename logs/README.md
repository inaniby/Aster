# logs/ — original version log moved out of README.md

This directory holds the version-by-version log that used to live in
`README.md` (moved 2026-11-26). It is the **raw log archive**: the wording is
the original README wording, grouped by version range. It is not the
condensed history — that is [`docs/VERSION_HISTORY.md`](../docs/VERSION_HISTORY.md),
which covers the same versions in rewritten form. The two are kept separate
on purpose: `logs/` preserves what was written at the time,
`docs/VERSION_HISTORY.md` is the maintained record.
